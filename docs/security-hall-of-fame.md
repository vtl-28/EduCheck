## How to Get Listed

1. **Discover a security vulnerability** in EduCheck
2. **Report it privately** via email to vtlehola23@gmail.com (see [SECURITY.md](../security.md))
3. **Allow us time to patch** the issue
4. **Get credited here** after the fix is deployed!

- ✅ Credit in release notes when fix is deployed

- ✅ Coordinated disclosure timing
